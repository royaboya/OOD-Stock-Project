- SETUP GUIDE -

To run the program, ensure the `CSVFiles` and `UserPortfolios` folder from the MVC Stock Program
are in the same directory as the jar file as well as their contents. Then, run the jar file as usual
from the same directory. To run the Text Based interface, use -text as the only argument
and to use the GUI, run the jar file as is with no arguments.

- PROGRAM INSTRUCTIONS -
To create a portfolio:
1. Enter option 5 in the menu prompt (Create a Portfolio)
2. Create a Portfolio and give it a name through option 1
3. Enter a name for the portfolio
4. Enter a ticker symbol and enter how many stocks to buy
5. After the portfolio was made, use option 2 to add two more stocks
5.1. Ensure the portfolio name is the same as before when adding a new stock, if unsure about
portfolio name/content, use option 3
6. To check portfolio value on a certain date, use option 5 and input the portfolio name and date
(in the format of YYYY-MM-DD) to check with. You will be prompted to input a valid date if the
inputted date is invalid.

- EXTRAS -
Default Supported Stocks. The stocks below have a supported date range from 1999-11-01 to
2024-06-20. Some exceptions to this date range are that the stock data will be unavailable on dates
where the stock market is usually closed such as on weekends and holidays.
